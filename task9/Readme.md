# Иерархия классов IterableObject

## Описание проекта

Проект демонстрирует применение объектно-ориентированного программирования в C++:
- Абстрактный класс с чисто виртуальными функциями
- Наследование (обычное и множественное)
- Виртуальное наследование для решения проблемы "алмаза"
- Полиморфизм (вызов методов через указатель на базовый класс)
- Шаблонные классы
- Работа с динамической памятью

## Иерархия классов
IterableObject<T> (абстрактный шаблонный класс)
│
├── String (работа со строками, T = std::string)
│
└── List<T> (шаблонный список, T может быть int, double, std::string)
│
└── StringList (множественное наследование от String и List<std::string>)

text

### Классы

| Класс | Описание |
|-------|----------|
| `IterableObject<T>` | Абстрактный базовый класс. Содержит чисто виртуальные методы `contains(const T&)`, `length()`, `getType()` |
| `String` | Класс для работы со строками в стиле C. Реализует поиск подстроки |
| `List<T>` | Шаблонный класс динамического массива. Поддерживает типы int, double, std::string |
| `StringList` | Класс с множественным наследованием от `String` и `List<std::string>`. Реализует поиск элемента, равного или содержащего подстроку |

## Требования к компиляции

- Компилятор: `g++` с поддержкой C++11 или выше
- ОС: macOS / Linux / Windows (с MinGW или WSL)

Интерфейс программы

Запустить тест — автоматическая проверка всех типов объектов

Тестирование

Тест (./program test) проверяет:

String::contains() — поиск подстроки
List<string>::contains() — точное совпадение в списке
StringList::contains() — поиск элемента, равного или содержащего подстроку
List<int>::contains() — поиск числа в списке
List<double>::contains() — поиск числа с плавающей точкой
Все вызовы contains() производятся через указатель на базовый класс IterableObject<T> для демонстрации полиморфизма.

Особенности реализации

Виртуальное наследование (virtual public IterableObject<T>) для предотвращения дублирования базового класса в StringList
Полная специализация шаблона List<std::string>::contains() для корректного поиска строк
Явное инстанцирование шаблона List<T> для типов int, double, std::string
Собственная реализация String на C-строках (без std::string внутри)
