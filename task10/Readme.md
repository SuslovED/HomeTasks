# Интерпретатор модельного языка программирования

## О проекте
Реализация интерпретатора модельного языка согласно варианту задания.  
Инструментальный язык: C++ (стандарт C++17).  
Сборка: утилита make.

## Состав проекта
- `Lex.h` – типы лексем и структуры для ПОЛИЗа.
- `Scanner.h`, `Scanner.cpp` – лексический анализатор (конечный автомат).
- `Parser.h`, `Parser.cpp` – синтаксический и семантический анализатор с генерацией ПОЛИЗа.
- `Executor.h`, `Executor.cpp` – интерпретатор ПОЛИЗа.
- `main.cpp` – точка входа (запуск анализатора и, опционально, выполнение).
- `Makefile` – сборка и тестирование.
- `tests/` – директория с тестовыми программами (A‑тесты и B‑тесты).

## Выбранные расширения языка (вариантная часть)

| Категория          | Реализованное расширение                                  |
|--------------------|-----------------------------------------------------------|
| I. Условные        | `if (выражение) оператор` (без else)                      |
| II. Циклы          | `do оператор while (выражение);`                          |
| III. Переходы      | `break;` и `continue;`                                    |
| IV. Типы данных    | `boolean` (логический тип, литералы `true`/`false`)       |
| V. Доп. операции   | унарный минус `-`                                         |
| VI. Логические выр.| полное вычисление (слева направо)                         |
| VII. Группировка фаз | двухпроходная: лексика+синтаксис+семантика+генерация ПОЛИЗа; интерпретация отдельно |

## Сборка
```bash
make
```

## Запуск
- Только анализ:  
  `./analyzer <файл_с_программой>`
- Анализ и исполнение:  
  `./analyzer <файл_с_программой> exec`

## Автоматическое тестирование
```bash
make test
```
Прогоняются все A‑тесты (корректные программы) и B‑тесты (программы с ошибками).  
A‑тесты дополнительно выполняются с аргументом `exec` и выводят результат работы.

## Список тестов

### A‑тесты (правильные программы)

| Файл                | Назначение                                                |
|---------------------|-----------------------------------------------------------|
| `tests/A1_sum.m`    | Сумма чисел от 1 до n (вводится n, выводится сумма)       |
| `tests/A2_bool.m`   | Логический тип, унарный минус, условный оператор          |
| `tests/A3_dowhile.m`| Цикл `do-while`, оператор `break`                         |
| `tests/A4_string.m` | Строковые операции (конкатенация, вывод)                  |
| `tests/A5_logic.m`  | Логические выражения и приоритеты                         |
| `tests/A6_nested_loops.m` | Вложенные циклы `while`, `continue`, `break`       |
| `tests/A7_string_ops.m` | Сравнение строк, конкатенация                         |
| `tests/A8_unary_arith.m` | Унарный минус, арифметика                           |
| `tests/A9_empty_comments.m` | Пустые операторы и комментарии `/* ... */`      |

### B‑тесты (программы с ошибками)

| Файл                | Ожидаемая ошибка                                          |
|---------------------|-----------------------------------------------------------|
| `tests/B1_undecl.m` | Использование необъявленной переменной `b`                |
| `tests/B2_badcondition.m` | Условие в `while` не `boolean` (целое)                |
| `tests/B3_break.m`  | `break` вне цикла                                         |
| `tests/B4_type.m`   | Присваивание несовместимых типов (`int` ← `string`)       |
| `tests/B5_not_int.m`| Применение `not` к целому числу                           |
| `tests/B6_minus_str.m` | Унарный минус к строке                                 |
| `tests/B7_continue_outside.m` | `continue` вне цикла                              |
| `tests/B8_compare_str_int.m` | Сравнение строки с целым                             |
| `tests/B9_read_bool.m` | Попытка ввода `boolean` переменной                    |
| `tests/B10_double_decl.m` | Повторное описание переменной `a`                   |
| `tests/B11_if_int.m` | Условие в `if` целое                                     |
| `tests/B12_break_outside.m` | `break` вне цикла (повтор)                          |
| `tests/B13_assign_str_int.m` | Присваивание строке целого числа                  |
| `tests/B14_desc_after_ops.m` | Описания после операторов                         |

## Формат сообщений об ошибках
При обнаружении ошибки выводится:
```
Analysis error: Error at line <строка>, col <столбец>: <описание>
```
Координаты соответствуют началу ошибочной лексемы.

## Примечания
- Идентификаторы могут иметь произвольную длину (ограничены только памятью).
- Строковые константы заключаются в двойные кавычки.
- Комментарии только вида `/* ... */`, вложенность не поддерживается.
- Интерпретатор гарантирует правильное выполнение всех конструкций выбранного подмножества языка.
